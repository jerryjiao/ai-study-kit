学习末期不再学新内容，只收割已有积累：金句速记、易错警示、必背清单、最后一天自查清单。

金句速记表

  • 改历史用 reset，补历史用 revert。
  • add 进暂存，commit 进版本库，status 看全局。
  • 权限三组：属主、属组、其他人；三位：读、写、执行。
  • 相对路径从当前目录出发，不从主目录出发。

易错警示 TOP 3

  1. 以为 git commit 会写暂存区——不会，它只消费暂存区。
  2. 共享历史上用 git reset——会让协作者的历史分叉，用 git revert。
  3. 把 ../bob/ 解析成「主目录下的 bob」——基准是当前目录。

必背清单

  • git 三区改动流向：工作区 → 暂存区 → 版本库
  • git log --oneline -5：最近 5 条提交的短列表
  • chmod +x 与 chmod 755 的含义
  • 权限字段三组三位的读法

最后一天自查清单

  1. 金句速记表能逐条默写
  2. 易错警示每条能说出「错在哪」
  3. 必背清单全部过一遍，生疏项回课程重读
  4. 错题中心的簇页面全部复看一遍
