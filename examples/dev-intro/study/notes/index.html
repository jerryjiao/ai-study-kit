知识点总结

1. git 的三个核心区域

改动流向是「工作区 → 暂存区 → 版本库」：git add 把工作区改动放进暂存区，git commit 把暂存区快照写入版本库。git status 随时查看各区状态。

2. 撤销改动：reset 与 revert 的区别

git reset 是「搬家」——把分支指针移到旧提交，适合本地未共享的历史；git revert 是「补偿」——生成一个反向提交，适合已推送的共享历史。记忆锚点：改历史用 reset，补历史用 revert。

3. Linux 权限的三组角色

权限字段（如 -rwxr-xr--）按「属主 / 属组 / 其他人」分三组，每组三位 rwx（读/写/执行）。改权限用 chmod，加执行权限：chmod +x deploy.sh。

4. 相对路径以「当前目录」为基准

../bob/ 表示先回到上一级再进入 bob 目录。路径解析永远从当前所在目录出发，而不是从用户主目录出发。
