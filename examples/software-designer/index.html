软件设计师复习课 · 目录

ai-study-kit 学习包　·　← mission（考点排布表）

十个学程块，每块约一周。顺序按「补弱 → 主场 → 案例 → 冲刺」编排：先补计算机基础，再回软工主场，最后跨点综合。

学程目录

  • D1 · 计算机系统基础——补码 / 校验码 / 流水线 / Cache / 可靠性
  • D2 · 操作系统——进程 / 死锁 / 存储管理 / 磁盘调度 / 文件系统
  • D3 · 计算机网络——OSI / 子网划分 / TCP / 应用协议 / 网络设备
  • D4 · 数据库——关系代数 / SQL / ER 模型 / 范式 / 事务
  • D5 · 软件工程基础——开发模型 / 需求分析 / 软件测试 / 项目管理 / 软件维护
  • D6 · 结构化分析与设计——数据流图 / 数据字典 / 模块设计
  • D7 · UML 与设计模式——用例图 / 类图 / 行为图 / 设计模式
  • D8 · 数据结构与算法——线性表 / 树 / 图 / 排序 / 散列
  • D9 · 数学 / 英语 / 法规——命题逻辑 / 概率统计 / 专业英语 / 著作权
  • D10 · 综合冲刺——易混概念 / 计算综合

怎么用：每天先到答题站刷当日档的题（错题自动进错题本），错题攒多后让 AI 出串讲；闪卡到期了先清卡。考点与题量的对应关系见 MISSION 排布表。
