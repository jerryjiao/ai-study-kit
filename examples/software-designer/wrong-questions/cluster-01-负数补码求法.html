错题精讲 · 负数补码：取反之后还要加 1

对应题目：SD-003　·　← 返回错题中心　·　相关课程：D1 · 计算机系统基础

SD-003（EP-01 补码 · D1）　→　课程：D1 第一节「补码：定点数表示与溢出判断」　→　闪卡：FC-SD-01（补码表示规则）、FC-SD-02（8 位补码范围）

这道题的错根很典型：求 -52 的补码，取反做了，末位加 1 漏了。选的 A「1100 1011」其实是 -52 的反码，正确答案是 C「1100 1100」。三个编码一步之差，差的就是最后那个加 1。

一、核心区别表

负数的三种机器数是「链条式」关系：原码 → 取反 → 反码 → 加 1 → 补码。以 -52（8 位）为例对着看：

编码负数怎么求8 位表示范围0 的表示-52 的编码
原码符号位 1 + 绝对值的数值位-127 ~ +127+0 / -0 两种1011 0100
反码原码符号位不变，数值位按位取反-127 ~ +127+0 / -0 两种1100 1011（← 本次错选）
补码反码末位加 1-128 ~ +1270 唯一1100 1100（正确答案）

范围差异不是巧合：补码把 ±0 两个编码省下一个给 -128，所以负方向比原码/反码多表示一个数。这张表右两列就是 SD-003 的全部陷阱。

二、决策流程

求负数 -N 的 8 位补码：
  ① 写 |N| 的原码            -52 → 52 = 0011 0100
  ② 符号位变 1，数值位取反     → 1100 1011（这是反码，别停！）
  ③ 末位加 1                  → 1100 1100（这才是补码）

自检（强烈建议每次都做）：
  补码 + |N| 的原码 = 1 0000 0000（即 2^8 进位丢弃）
  1100 1100 + 0011 0100 = 1 0000 0000 ✓ 对上了

反向（已知补码求真值）：
  符号位为 1 → 数值位取反加 1 得 |X|，真值 = -|X|
  例：1110 0110 → 0001 1001 + 1 = 0001 1010 = 26 → X = -26

三、易错警示

错根 1：取反之后忘了加 1，把反码当补码交卷。

真相：本题选项 A 就是设计好的反码陷阱。背口诀「负数补码 = 反码 + 1」，写完取反笔别停，加完 1 再看选项。

错根 2：符号位到底取不取反，两种操作混着记。

真相：求负数补码时符号位保持 1，只翻数值位；而「已知补码求相反数的补码」才是连同符号位一起取反加 1。课程里这两条规则是分开列的，别合成一条。

记忆锚点：1000 0000 在补码里是 -128，它在原码/反码里没有对应真值——「负数多表示一个」「0 唯一」两个性质都从这来。判断题拿 ±0 或 -128 偷换概念时，先想这格表。

四、变体训练

同一考点换个问法，做完再展开答案：

变体 1：求 -100 的 8 位补码，并写成十六进制。

对一下答案

+100 = 0110 0100 → 符号位 1、数值位取反得 1001 1011 → 加 1 得 1001 1100，十六进制 9CH。自检：1001 1100 + 0110 0100 = 1 0000 0000 ✓

变体 2：8 位补码 1100 1011（你本次错选的那个码字）表示的真值是多少？

对一下答案

符号位 1，负数。数值位取反加 1：1000 1011……更快的做法是连同符号位取反加 1：0011 0100 + 1 = 0011 0101 = 53，所以真值是 -53。错选的 A 其实是 -53 的补码，不是 -52 的——差的就是那个 1。

变体 3：已知 X 的 8 位补码是 1110 0110，X = ？

对一下答案

连同符号位取反：0001 1001，加 1：0001 1010 = 26，X = -26。正向求补和反向求真值用的是同一套「取反加 1」，方向相反。
