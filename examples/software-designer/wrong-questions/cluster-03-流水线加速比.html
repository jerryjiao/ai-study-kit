错题精讲 · 流水线加速比：段数越多不等于越快

对应题目：SD-021　·　← 返回错题中心　·　相关课程：D1 · 计算机系统基础

SD-021（EP-03 流水线 · D1）　→　课程：D1 第三节「流水线：周期、总时间、吞吐率、加速比」　→　闪卡：FC-SD-05（流水线执行时间公式）

判断题「段数划分得越多，实际加速比就一定越大」，你选了「对」。错根不在流水线本身，而在没盯住题干里的「一定」两个字——理想模型里段数越多加速比确实趋近段数 k，但实际约束一上，「一定」就不成立了。

一、核心区别表

理想模型 vs 实际约束，逐个维度对：

维度理想模型实际约束（「一定」翻车的地方）
段数 k 与加速比 Sk 越大，S 越接近 kS 趋近 k 但永远达不到；k 越大断流代价越重
流水线周期 Δt各段均衡，都等于 ΔtΔt = max（各段时间），最慢的段说了算；切得越碎越难均衡
指令供给指令连续流入指令相关、冲突、转移让流水断流，段数多了断流损失更大
额外开销忽略段间锁存器开销随段数累积，吃掉增益

结论就一句：实际加速比取决于各段均衡程度和指令能否连续流入，「段数多 → 加速比一定大」不成立。这正是 SD-021 的解析口径。

二、决策流程

见到「段数越多……就越 / 一定……」类命题，走三问：

  ① 各段耗时会均衡吗？
     否（切段越细越难切匀，Δt 被 max 拖住）──┐
  ② 指令能连续流入吗？                        │ 任一「否」
     否（相关 / 冲突 / 转移导致断流）─────────┼──→ 命题不成立，
  ③ 段间锁存开销可忽略吗？                    │      选「错」
     否（开销随段数累积）────────────────────┘

  计算类口径（课程三条公式）：
    Δt = max(各段时间)（题目未给锁存时间则忽略）
    T = 第一条指令完整时间 + (n-1) × Δt
    S = 串行执行总时间 / T      （S < k，趋近不等于达到）
  最大吞吐率 = 1/Δt，与指令条数无关。

三、易错警示

错根 1：对「一定」「就越」这类绝对化措辞不设防。

真相：判断题里的绝对化表述，默认请你找反例——本题的反例就是「各段耗时严重不均衡时，周期被最慢段拖住，段数再多也快不起来」。理想结论（S 趋近 k）加上「一定」就变成错误命题。

错根 2：以为切段越多周期越小。

真相：周期由最慢的段决定（Δt = max），不是平均值。把一条 6ns 的段切成 10 份，只要其中一份 4ns，周期就是 4ns，其余切了白切。

记忆锚点：「趋近 k，达不到 k」+「最慢的段说了算」。这两句同时管住判断题（SD-021 这类）和计算题（加速比永远算出 S < k）。

四、变体训练

同一考点换个问法，做完再展开答案：

变体 1：某流水线分 5 段，耗时 2ns、3ns、4ns、3ns、2ns，连续输入 20 条指令，全部完成需要多久？

对一下答案

Δt = max = 4ns；第一条完整时间 = 2+3+4+3+2 = 14ns；T = 14 + 19×4 = 90ns。注意各段不等长，不能直接套 (k+n-1)×Δt，必须先算第一条的完整时间。

变体 2：3 段流水线每段 2ns，连续执行 1000 条指令且无冲突，与顺序执行相比加速比约是多少？

对一下答案

T = 6 + 999×2 = 2004ns；顺序执行 = 1000×6 = 6000ns；S = 6000 / 2004 ≈ 3.0（实为 2.99）。理想段数是 3，实际永远差一点——这就是「趋近 k，达不到 k」的数值版。

变体 3：判断：流水线的最大吞吐率为 1/Δt，与指令条数无关。

对一下答案

对。n 趋向无穷时 T ≈ n×Δt，TP = n/T 趋向 1/Δt。这条恰好是「没有一定/就越」的客观陈述——和 SD-021 对比着记：绝对化命题找反例，客观公式直接判。

  • 错题 → 闪卡：FC-SD-05（流水线执行时间公式）覆盖 T 与 S 的计算锚点，未毕业前每天过。
