错题精讲是四对齐的第四层——刷完题后，把未毕业错题按考点聚类，每簇深度展开为：核心区别表 + 决策流程 + 易错警示 + 变体训练。当前批次来自 D1 档（计算机系统基础）的三道错题，覆盖 EP-01 ~ EP-03 三个考点。

🔥 易错点精讲 · 未毕业错题深挖

→ 负数补码：取反之后还要加 1

1 题

SD-003（EP-01）错点。求 -52 的补码停在反码，末位加 1 漏了——选的 A 是反码 1100 1011，正确是 C 1100 1100。一表理清原码/反码/补码的链条差异与 -128 的来历，附「补码+|N| 进位自检」和三个变体。

→ 校验码能力边界：奇偶 / 海明 / CRC

1 题

SD-014（EP-02）错点。多选只选了 A——奇偶校验的短板判对了，CRC「检错更强、数据链路层标配」两条正面属性漏选。能力表（奇偶检 1 不纠 / 海明检 2 纠 1、2^r ≥ k+r+1 / CRC 只检不纠）+ 逐项判定 + 三个变体。

→ 流水线加速比：段数越多不等于越快

1 题

SD-021（EP-03）错点。判断题把「实际加速比一定越大」选成「对」——漏看了「一定」：周期由最慢段决定（Δt = max），相关冲突断流、锁存开销累积都会吃掉增益，S 只趋近 k 达不到 k。理想 vs 实际对比表 + 三问判定流程 + 三个变体。

怎么用这几页

  1. 先读对应簇的「核心区别表」和「决策流程」，再合上页面在草稿纸重推一遍。
  2. 做「变体训练」：先自己算/判，再展开答案对照；错任何一个变体，回课程对应节重看公式。
  3. 错题未毕业（答对次数未达毕业阈值）前，相关闪卡（FC-SD-01 ~ FC-SD-05）每天随复习队列过。
