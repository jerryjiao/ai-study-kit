多选只选了 A：奇偶校验「检不出偶数个错、不能定位」判对了，但 C「CRC 检错能力比奇偶强」、D「CRC 广泛用于数据链路层」两条送分属性没敢选。多选题的策略不是「不确定就不选」，是把三种校验码的能力边界背成一张表，逐项对号。

一、核心能力表

课程里「三兄弟」一张表记全，做题时默画一遍：

校验码原理检纠错能力必背口径
奇偶校验加 1 位校验位，把 1 的个数配成奇 / 偶只能检奇数个位错，不能定位纠错两位同错则奇偶性不变，恰好漏检
海明码校验位放在 2^i 号位，分组奇偶校验检 2 位错 / 纠 1 位错2^r ≥ k + r + 1（k=信息位，r=校验位，取最小 r）
CRC信息位补 0 后对生成多项式做模 2 除检错能力强，只检不纠冗余位数 = 生成多项式最高次幂；余 0 判无错

再把 SD-014 四个选项过一遍判：

选项判定依据
A 奇偶只能检奇数个位错、不能定位对（已选 ✓）能力边界就是「检 1 不纠」
B 奇偶能发现所有偶数个位错错两位同时翻转，1 的个数奇偶性不变——偶数个错恰好检不出
C CRC 检错能力比奇偶强对（漏选）模 2 除生成多项式，可检多位错，能力远强于奇偶
D CRC 广泛用于数据链路层对（漏选）链路层帧差错检测的标准做法，教材固定口径

二、决策流程

见到校验码的多选 / 判断，逐项走这棵树：

  这条说法在说哪种校验码？
        │
        ├─ 奇偶 ──→ 能纠错吗？否。能定位吗？否。
        │            检几个？只检奇数个位错（偶数个恰好漏检）
        │
        ├─ 海明 ──→ 能纠几位？只纠 1 位。
        │            检几位？检 2 位。位数靠 2^r ≥ k+r+1
        │            （k=信息位，r=校验位，r 取最小可行值）
        │
        └─ CRC  ──→ 能纠错吗？不能，只检不纠。
                     亮点在「检错强 + 链路层标配」→
                     见到这两句正面描述，直接判对

  多选策略：先按表定性，再逐项打勾；
  漏选和错选同样丢分，判得准的属性就选上。

三、易错警示

错根 1：对 CRC 的「正面属性」不熟，只敢选自己错过的地方（A）。

真相：「检错能力比奇偶强」「广泛用于数据链路层的差错检测」是 CRC 的两条标准描述，属于送分项。能力表背牢，正面属性和短板一样都要认得。

错根 2：以为奇偶校验至少能发现「两位同错」。

真相：恰好相反——两位同时出错，1 的个数的奇偶性不变，校验位对不上变化，偶数个位错检不出。B 选项就是拿这句话反着说。

错根 3：海明码能力记串，写成「检 1 纠 2」或「能纠 2 位」。

真相：固定口径「检 2 位错、纠 1 位错」，位数用 2^r ≥ k + r + 1（k=信息位，r=校验位）。注意课程和闪卡里字母用法有差异时，以课程口径为准。

四、变体训练

同一考点换个问法，做完再展开答案：

变体 1：用海明码对 16 位信息进行校验，至少需要几位校验位？

对一下答案

k = 16，找最小 r 使 2^r ≥ k + r + 1。r = 4：16 ≥ 21 不成立；r = 5：32 ≥ 22 成立 → 5 位。别忘了不等式右边也要加上 r 本身，r=4 时右边是 21 不是 17。

变体 2：判断：CRC 接收方将收到的码字对生成多项式做模 2 除法，余数为 0 则认为传输未发生差错。

对一下答案

对。余 0 判无错是 CRC 接收方的标准判定；模 2 除 = 逐位异或不借位，冗余位数 = 生成多项式最高次幂。

变体 3：多选：关于海明码，下列说法正确的有？
A. 对 4 位信息位编码，至少需要 3 位校验位　B. 校验位放在位号为 2 的幂（1、2、4、8…）的位置上　C. 增大码距可以提高检错与纠错能力　D. 海明码能自动纠正同时发生的 2 位错误

对一下答案

ABC。2^3 = 8 ≥ 4 + 3 + 1 = 8 成立，A 对；B 是海明码的放置规则；码距越大检纠能力越强，C 对；海明只能检 2 纠 1，纠不了 2 位，D 错。
