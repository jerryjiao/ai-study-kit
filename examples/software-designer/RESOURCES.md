# Resources: software-designer 参考材料

> 产课与出题的概念来源以权威材料为准（方法论：概念/定义/方法论的来源是高质量材料，优先级高于凭空推测）。

## 一、权威来源（概念基准）

1. **考核大纲**——全国计算机技术与软件专业技术资格（水平）认证《软件设计师考核大纲》（官方发布，界定考点范围与深度，本包排布表的依据）。
2. **官方教程**——《软件设计师教程》（官方指定教程）：章节结构对应 D1–D9 各学程块，概念定义以其为准。
3. **历年真题（考点频次参考）**——真题原文不入库（版权），仅作考点出现频次与题型分布的统计参考：上午综合知识 75 单选的分值分布、下午案例五大题型（数据流图 / 数据库设计 / UML 建模 / 算法分析 / 面向对象设计）的轮换规律。

## 二、使用规则

- 题面与解析**全原创**，只对齐考点分布，不搬运真题文句。
- 概念冲突时：考核大纲 > 官方教程 > 通用教材共识。
- 涉及具体计算（流水线加速比、子网划分、可靠性、关键路径等）以官方教程的公式与口径为准，解析中给出计算过程。

## 三、学习者画像（产课深度校准）

在职开发者：git/Linux/编程熟练，数据结构与算法有实操直觉但理论口径需校准；计算机组成 / OS / 网络 / 离散数学 / 法规为薄弱面，课程侧重「概念准确定位 + 计算套路」，不从零科普。
