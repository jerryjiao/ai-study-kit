一、高频易混概念清单（8 组）

易混概念的丢分特征是「都觉得对」——对策是每对只记一个判别信号：

易混概念对一句话区分判别信号
重载 overloading同一类里同名不同参（个数/类型），编译期定看参数表改没改 vs 看继承链与签名是否一致
重写 overriding子类重新实现父类同名同参方法，运行期多态
TCP面向连接、可靠、字节流、点对点，开销大要可靠选 TCP，要快/广播选 UDP
UDP无连接、不可靠、数据报、支持广播，开销小
编译整体翻译成目标程序再执行，跨平台性差、执行快有没有先生成的独立目标文件
解释边翻译边执行、不生成独立目标程序，调试方便
聚合 aggregation空心菱形；整体与部分可分离（车队—汽车）删整体时部分是否跟着消失
组合 composition实心菱形；部分随整体共存亡（订单—订单项）
黑盒测试只看输入输出，不看内部结构（等价类/边界值）知不知道程序内部逻辑
白盒测试按内部逻辑路径覆盖（语句/判定/条件/路径覆盖）
进程资源分配的独立单位，有独立地址空间，切换开销大有没有独立地址空间
线程调度的基本单位，共享所属进程资源，切换开销小
包含 «include»基用例必然执行被包含用例（借书必校验证件）箭头方向也相反：基→包含；扩展→基
扩展 «extend»满足条件才执行（逾期才缴罚金）
耦合模块间联系程度，越低越好（七级：非直接→…→内容）一个对内、一个对外，都要背排序
内聚模块内联系程度，越高越好（功能→…→偶然）

易混概念复习法：不要背两张孤立名词表——每次都把两个词放在一句话里对撞（如「重载编译期、重写运行期」），错题本里按对归堆，临考只扫判别信号列。

重载（编译期）

同一个类里，方法名相同、参数表不同（个数/类型/顺序）。返回类型不参与判别。绑定发生在编译期。

重写（运行期）

子类对父类同名同参方法重新实现，访问权限不能更严格。通过父类引用调用时按实际对象绑定——多态的来源。

聚合（空心菱形）

整体—部分关系但生命周期独立：车队解散，汽车还在。部分可同时属于多个整体。

组合（实心菱形）

部分随整体共存亡：删除订单，订单项一并删除。部分通常只属于一个整体，是更强的拥有关系。

二、计算综合演练（3 个必拿算例）

计算综合的题型十年不变：给场景 → 认出公式 → 代数。练的是「认型」这一步。

算例 1：子网划分（D3 回炉）

把 192.168.1.0/24 平均分成 4 个子网，求掩码、每网主机数，并判断 192.168.1.100 属于哪个子网：

① 借 2 位：2² = 4 个子网 → 掩码 /26 = 255.255.255.192
② 主机位剩 6 位：2⁶ - 2 = 62 台/网（减网络地址与广播地址）
③ 块大小 = 256 - 192 = 64，子网起点 0 / 64 / 128 / 192
   子网          可用范围              广播地址
   .0/26        .1 ~ .62             .63
   .64/26       .65 ~ .126           .127   ◀ 100 落在此网
   .128/26      .129 ~ .190          .191
   .192/26      .193 ~ .254          .255
④ 192.168.1.100 → 所在子网 192.168.1.64/26，广播 .127

算例 2：可靠性（D1 回炉）

串联相乘、并联「先补失败再相乘」：

R串联 = R1 × R2 × …            R并联 = 1 - (1-R1)(1-R2)…

系统：两个 R=0.9 的部件并联，再与一个 R=0.9 的部件串联：
并联段 = 1 - (1-0.9)(1-0.9) = 1 - 0.01 = 0.99
系统   = 0.99 × 0.9 = 0.891

算例 3：关键路径（AOE 网，D8/D10 综合）

事件结点图，活动的最早开始 = 弧尾事件最早时刻；总时差 = 最迟开始 − 最早开始：

        A(3)      C(4)
    ①──────▶②──────▶④
    │                ▲   E(2)
    │ B(2)   D(6)    │
    └──────▶③───────┘ ⑤
事件最早时刻：v1=0, v2=3, v3=2, v4=max(3+4, 2+6)=8, v5=8+2=10
工期 = 10；关键路径 = ① B ③ D ④ E ⑤（总时差全 0）
A 的总时差 = LS-ES = 1-0 = 1（A 的 ES=0，LS = v2 最迟 4 − 时长 3 = 1，可拖延 1 天不影响工期）

认型口诀：见「借位/掩码/主机数」→ 子网；见「串并联图 + 概率」→ 可靠性；见「箭头带天数 + 问工期/最短」→ 关键路径。三类占计算综合的大头，公式以上三个算例为模板。

计算综合的三个高频栽点：① 主机数忘减 2（去掉网络地址与广播地址）；② 并联可靠性公式是「1 减失败概率之积」，别直接拿 R 相乘；③ 关键路径取最长路径而非最短，活动总时差 = LS − ES，只有关键活动为 0。
