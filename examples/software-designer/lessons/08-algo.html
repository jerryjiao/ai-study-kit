这是开发者的主场，但考法和你日常写代码不同——软考不问工程取舍，问性质、复杂度、遍历互推。五条线：线性表、树、图、排序、散列，每条线都有固定的「必得计算分」。

一、线性表：栈与队列的口径题

线性表两种存法：顺序表（随机存取 O(1)、插删要挪元素）与链表（存取 O(n)、插删改指针即可）。两个受限的线性表是考点钉子户：

  • 栈（Stack，LIFO）：进栈出栈序列合法性判断——任意时刻已出栈的最大值之后的元素只能按逆序出（经典判断题）。
  • 队列（Queue，FIFO）：循环队列牺牲一格判满：(rear+1)%m == front 为满，front == rear 为空，元素个数 (rear-front+m)%m。
循环队列 m=6：front=2, rear=5  →  元素个数 = (5-2+6)%6 = 3（下标 2,3,4）

顺序表

随机存取 O(1)；插删平均移动 n/2 个元素；存储密度高，需要连续空间，扩容昂贵。

单链表

按序存取 O(n)；定位后插删只改指针 O(1)；要额外存指针域，空间可离散分配。

二、树：性质、遍历互推、哈夫曼

二叉树三大性质：第 i 层最多 2i-1 个结点；深度为 k 的二叉树最多 2k-1 个结点；叶子数与度为 2 结点数恒有 n0 = n2 + 1（选择题年年出）。n 个结点的完全二叉树深度为 ⌊log₂n⌋+1。

遍历互推（下午算法题的入门题型）——已知先序＋中序，推后序：

        A                先序：A B D E C F（根左右）
       / \               中序：D B E A C F（左根右）
      B   C              后序：D E B F C A（左右根）
     / \    \
    D   E    F
推法：① 先序首字母 A 为根；② 中序里 A 左侧 DBE 是左子树、右侧 CF 是右子树；
      ③ 对左子树递归：先序 B D E → 根 B，中序 D B E → 左 D 右 E；
      ④ 对右子树递归：根 C，中序只剩 F → F 是 C 的孩子（先序 C F 定 F 在后）；
      ⑤ 按「左右根」拼后序：D E B F C A。

哈夫曼树（Huffman）：每次取两个最小权值合并，n 个叶子的哈夫曼树共 2n-1 个结点、无度为 1 的结点。带权路径长度 WPL 算例：

权值 {2, 3, 4, 6}
第 1 步：2 + 3 = 5      →  {4, 5, 6}
第 2 步：4 + 5 = 9      →  {6, 9}
第 3 步：6 + 9 = 15     →  根
WPL = 6×1 + 4×2 + 2×3 + 3×3 = 6 + 8 + 6 + 9 = 29
（捷径：WPL = 各次合并之和 = 5 + 9 + 15 = 29，两条路必相等，可互验）

三、图：存储、遍历、三个经典算法

图的两种存储（选择题常对比空间）：

存储空间适用查边
邻接矩阵O(n²)稠密图O(1) 直接查格子
邻接表O(n+e)稀疏图O(度) 沿链扫
  • 遍历：深度优先 DFS（栈/递归，沿一条路走到黑再回溯）、广度优先 BFS（队列，逐层扩散）；邻接表下复杂度都是 O(n+e)。给顶点序列判断是 DFS 还是 BFS 是高频选择题。
  • Dijkstra：单源最短路径，贪心地按「当前最短」逐点收编，不适合负权边。
  • 拓扑排序：AOV 网上反复挑入度为 0 的顶点输出并删其出边；结果不唯一；若输出顶点数 < 总数说明网中有环。
AOV：V1→V2, V1→V3, V2→V4, V3→V4, V4→V5
拓扑：入度 V1=0 起 → V1 → (V2 或 V3，不唯一) → V4 → V5

关联记忆：AOV 网（顶点=活动）配拓扑排序查依赖；AOE 网（边=活动）配关键路径求工期——后者在 D10 的计算综合演练里出算例。

直接插入O(n²)O(n²)O(1)稳定
希尔O(n1.3)O(n²)O(1)不稳定
冒泡O(n²)O(n²)O(1)稳定
简单选择O(n²)O(n²)O(1)不稳定
快速O(nlogn)O(n²)（已有序最坏）O(logn)不稳定

记忆锚点：不稳定口诀「快些选堆不值钱」——快排、希尔（些）、选择、堆排不稳定，其余（直接插入、冒泡、归并、基数）都稳定。快排最坏情况是序列已经基本有序；「最快不确定、最稳是归并（空间 O(n)）」。

五、散列：冲突处理与装填因子

散列（Hash）用 H(key) = key mod p（p 常取不大于表长的素数）直接定址。冲突（不同关键字同址）的处理两大家：

  • 开放定址法：冲突后按规则探测下一空位——线性探测（+1 往后找，易「堆积」）、二次探测（±1², ±2²…）、随机探测。
  • 链地址法：同址关键字挂成单链表，删插友好。
H(k) = k mod 7，表长 7，线性探测插入 {26, 38, 12, 51, 31}：
26%7=5 → 槽 5        38%7=3 → 槽 3
12%7=5 → 冲突 → 槽 6   51%7=2 → 槽 2
31%7=3 → 冲突 → 槽 4（跳过被 26 占的 5）

下标：  0    1    2    3    4    5    6
        -    -   51   38   31   26   12

平均查找长度 ASL 随装填因子 α = 表中记录数 / 表长 增大而上升——α 是影响冲突频率的首要因素，与关键字本身无关。
