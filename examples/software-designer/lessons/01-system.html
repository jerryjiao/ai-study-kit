上午综合知识卷里，计算机系统基础是稳定的「送分计算题」来源：补码求值、校验码位数、流水线吞吐率、Cache 命中率、可靠性串并联——五类题几乎每年必出且套路固定。本课每节直给公式与算例，刷题前过一遍即可上手。

一、补码：定点数表示与溢出判断

机器数有原码、反码、补码三种编码，软考偏爱考补码的原因很简单：加减法统一为加法、0 的表示唯一。必背口径（n 位定点整数）：

原码范围：-(2^(n-1)-1) ~ +(2^(n-1)-1)    （+0 / -0 两种 0）
反码范围：-(2^(n-1)-1) ~ +(2^(n-1)-1)    （+0 / -0 两种 0）
补码范围：-2^(n-1)     ~ +(2^(n-1)-1)    （0 唯一，负数多表示一个）

即 8 位补码的范围是 -128 ~ +127。两条高频计算规则：

  • 求负数的补码：先写其绝对值的原码，符号位保持 1，数值位取反后加 1。
  • 已知补码求相反数的补码：连同符号位一起取反加 1。

算例：求 -100 的 8 位补码。+100 = 0110 0100 → 数值位取反得 1001 1011 → 末位加 1 得 1001 1100，即十六进制 9CH。

变形补码（双符号位补码）用于加减运算的溢出判断：双符号位 00 为正常正数、11 为正常负数；01 表示正溢出（上溢），10 表示负溢出（下溢）——两符号位相异即溢出，这是判断题的常客。

易错点：「负数多表示一个」「0 的表示唯一」都是补码独有性质，判断题常拿原码/反码的 ±0 偷换概念。变形补码口诀再念一遍：符号位相同未溢出，01 正溢、10 负溢。

二、校验码：奇偶 / 海明 / CRC

校验码考「三兄弟」，一张表记全能力边界：

校验码原理检纠错能力必背公式
奇偶校验码添加 1 位校验位，使 1 的个数为奇数 / 偶数只能检 1 位错，不能纠错定位—
海明码校验位放在 2^i 号位，分组奇偶校验检 2 位错 / 纠 1 位错2^r ≥ k + r + 1
循环冗余校验码（CRC）信息位补 0 后模 2 除生成多项式检错能力强，不纠错余数即冗余位

海明码公式中 k 是信息位数、r 是校验位数，r 取满足不等式的最小值。算例：k = 4 时试 r = 2（2² = 4 ≥ 4+2+1 = 7？不成立），r = 3（2³ = 8 ≥ 4+3+1 = 8，成立）→ r = 3，海明码总长 7 位。

CRC 计算套路（模 2 除法 = 逐位异或，不借位）：生成多项式 G(x) = x³ + x + 1 对应 1101；信息位 1010 后补 3 个 0 得 1010000，模 2 除以 1101，余数替换掉补的 0 就是发送帧；接收方用同一多项式再除，余 0 判无错。冗余位数 = 生成多项式最高次幂。

记忆锚点：奇偶检 1 不纠；海明「2^r ≥ k+r+1」纠 1 位错；CRC 只检不纠。三个校验码的检纠能力要能排序，这是多选题的固定玩法。

三、流水线：周期、总时间、吞吐率、加速比

指令流水线把一条指令切成若干段（取指、分析、执行……），各段同时处理不同指令。三条公式打天下：

流水线周期 Δt = max(各段时间) + 锁存器开销（题目未给锁存时间则忽略）

执行 n 条指令的总时间：
  T = 第一条指令完整时间 + (n-1) × Δt
  （当各段时间都恰为 Δt 时，等价于 T = (k + n - 1) × Δt）

吞吐率 TP = n / T        加速比 S = 串行执行总时间 / T

算例：三段流水线取指 1ns、分析 2ns、执行 3ns，执行 10 条指令。周期 Δt = max(1, 2, 3) = 3ns；第一条完整时间 = 1+2+3 = 6ns；T = 6 + 9×3 = 33ns；吞吐率 TP = 10/33 ≈ 0.3 条/ns；加速比 S = 10×6 / 33 ≈ 1.8。若题目问「最大吞吐率」，答案是 1/Δt，与指令条数无关。

易错点：总时间不是「n × 第一条时间」，而是「首条完整 + (n−1)×周期」。各段时间不等时必须先算第一条的完整时间；(k+n−1)×Δt 只有各段都等于 Δt 时才能直接套。流水线段数增加，加速比趋近段数 k，但永远达不到。

四、Cache：三种地址映射与命中率

Cache（高速缓冲存储器）存放主存的活跃副本，为的是弥合 CPU 与主存的速度差。考点就两块：地址映射结构与命中率计算。

映射方式主存块能放哪主存地址划分特点
直接映射唯一一块（主存块号 mod Cache 块数）标记 | Cache 块号 | 块内地址硬件简单，冲突率高
全相联映射任意空块标记 | 块内地址冲突率低，比较电路贵
组相联映射组间直接、组内全相联标记 | 组号 | 块内地址前两者折中，最常用

地址位数算例：主存地址 24 位，Cache 分 64 块、每块 16B。块内地址 = log2(16) = 4 位；直接映射下 Cache 块号 = log2(64) = 6 位；标记 = 24 − 6 − 4 = 14 位。若是组相联（如每组 2 块），组号 = log2(32) = 5 位，标记变 15 位——划分口径变了，位数跟着变。

命中率算例：Cache 存取 20ns、主存 100ns、命中率 95%。按「未命中直接访主存」口径：平均访问时间 = 0.95×20 + 0.05×100 = 24ns；若题目按「未命中先查 Cache 再访主存」口径，则为 0.95×20 + 0.05×(20+100) = 25ns。先看清题面口径再代公式。

记忆锚点：Cache 对程序员透明、内容由硬件调度；「标记 | 号 | 块内」从左到右位数递减，谁在中间看映射方式（直接是块号、组相联是组号、全相联没有号）。命中率口径两种，答案差一次 Cache 时间。

五、可靠性：串联与并联

可靠性计算只考两个基式和它们的组合：

串联（一坏全坏）：R = R1 × R2 × … × Rn
并联（全坏才坏）：R = 1 − (1−R1)(1−R2)…(1−Rn)

串联：  ──[R1]──[R2]──                R = R1×R2
并联：     ┌─[R1]─┐
         ──┤      ├──                R = 1−(1−R1)(1−R2)
           └─[R2]─┘

算例：两个子系统可靠性均为 0.9——串联时 R = 0.9×0.9 = 0.81；并联时 R = 1 − (0.1)² = 0.99。混合系统先算每条支路内部的串联积，再把各支路按并联式合并。串得越多可靠性越低、并得越多越高——这就是冗余设计提升系统可靠性的数学依据。

易错点：可靠性框图中的「串 / 并」是功能依赖关系，不是电路画法。做题先判断「一个坏系统就坏」还是「都坏才坏」，再套串联乘、并联「1 减失效概率之积」，别被图形外观带偏。
