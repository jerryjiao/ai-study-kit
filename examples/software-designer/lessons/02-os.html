D2 · 操作系统

ai-study-kit 学习包　·　← mission　·　下一课：D3 · 计算机网络

OS 是上午题的稳定得分区：进程状态转换与 PV、死锁条件、存储管理的页式地址变换、磁盘调度与文件系统的组织。概念辨析多于计算，背准口径就行。

一、进程与同步

进程是程序在数据集上的一次运行，是资源分配的独立单位；线程是调度的基本单位，同进程内线程共享地址空间。

        唤醒                    时间片到/被抢占
  就绪 ──────▶ 运行 ──────────────▶ 就绪
   ▲            │ 等待资源（I/O、P 操作）
   └── 调度 ──┐  ▼
              等待 ──资源满足──▶ 就绪
  • 三态模型没有「运行→等待」由自身触发之外的路；五态模型加入挂起（活跃/静止）。
  • PV 操作（信号量）：P 申请（减 1，负值表示排队等待者数量），V 释放（加 1，唤醒）。
  • 生产者-消费者：互斥信号量初值 1，缓冲区空/满两个同步信号量，先同步后互斥。

易错：信号量为负时其绝对值 = 等待进程数；「先 P 互斥再 P 同步」可能死锁，顺序必须同步在前。

二、死锁

死锁四个必要条件：互斥、保持等待（占有且等待）、不剥夺（不可抢占）、环路等待——破坏任一即可预防。

  • 处理策略：预防（静态破坏条件）、避免（银行家算法动态判断安全状态）、检测与解除。
  • n 个进程各需 k 个资源，系统不发生死锁的最少资源数 = n×(k−1) + 1。例：3 进程各需 4 → 3×3+1 = 10。
  • 银行家算法找「安全序列」：能全部分配完成的顺序存在即安全。

三、存储管理

存储管理的核心是地址重定位与离散分配：页式（等大页，物理离散）、段式（逻辑单位，便于共享保护）、段页式（先段后页）。

页式地址变换：逻辑地址 = 页号 + 页内偏移
  页大小 4K，逻辑地址 2500 → 页号 0，偏移 2500
  页表 0#页 → 物理块 2 → 物理地址 2×4096 + 2500 = 8644（若块号从 0 起且页大小 4K 时块基址 = 块号×4096）
快表 TLB 命中可省一次访存；缺页中断属程序性中断，需调页并可能置换。
  • 页面置换算法：OPT（最佳，不存在，用于对比）、FIFO（可能 Belady 异常）、LRU（最近最少使用）。
  • Belady 异常：FIFO 中物理块增多、缺页反而增多——判断题常考。
  • 虚存 = 局部性理论 + 离散分配 + 请求调页，容量由地址结构决定而非外存大小。

四、磁盘调度

磁盘调度决定磁头服务请求的次序，目标是降寻道时间。

算法策略特点
FCFS先来先服务公平，寻道长
SSTF最近的先服务可能有饥饿
SCAN（电梯）沿一个方向扫到端点再折返两端均衡
C-SCAN单向扫描，到端点回起点重扫等待时间更均匀
磁头 52，请求 65,38,18,80（SSTF）：52→65→80→38→18，共 28+15+42+20 = 105 道

五、文件系统

文件系统负责外存上数据的命名、组织与存取。考点集中在物理结构与索引。

  • 物理结构：连续（随机快、难扩展）、链接（易扩展、只能顺序）、索引（一张索引表支撑随机访问）。
  • UNIX 三级索引：直接块 + 一级/二级/三级间接索引，算「最大文件长度」是经典计算题。
  • 位示图法管理空闲块：bit=1 表示占用，字长 32 位时块号与（字号, 位号）互相换算。
  • 文件目录实现按名存取；多级目录解决重名；FAT 是显式链接表。

记忆锚点：进程看「态」，页式看「表」，磁盘看「道」，文件看「索引」——四个考点各抓一个字。
