一、OSI 参考模型

OSI 七层自下而上：物理、数据链路、网络、传输、会话、表示、应用。

层功能关键词典型协议/PDU
应用层面向用户的服务HTTP、FTP、SMTP、DNS
表示层编码、压缩、加密JPEG、加密格式
会话层建立/管理/终止会话RPC
传输层端到端可靠传输TCP、UDP · 段
网络层路由与逻辑寻址IP、ICMP · 分组
数据链路层成帧、差错检测、MAC 寻址以太网 · 帧
物理层比特流传输RS-232 · 比特

TCP/IP 四层模型是 OSI 的工程简化：网络接口、网际、传输、应用。分层记忆口诀「物链网传会表应」。

二、子网划分

子网划分从主机位借位做子网号，核心工具是按位与。

例：192.168.37.65/26
 掩码 255.255.255.192 → 块大小 64
 65 ÷ 64 → 落在第 1 块（64~127）→ 网络地址 192.168.37.64
 可用主机 = 2⁶ − 2 = 62（去网络地址与广播地址）
 广播地址 192.168.37.127
 判断同网：两 IP 与掩码按位与结果相同即同子网
  • CIDR 聚合反向借位：/22 = 4 个连续 /24 汇成一条路由。
  • 私有地址三段：10/8、172.16/12、192.168/16——判断题常客。

易错：可用主机数要减 2；「网络地址」是主机位全 0，「广播地址」是主机位全 1。

三、TCP 与 UDP

TCP 面向连接、可靠、字节流；UDP 无连接、不可靠但开销小、实时性好。

  • 三次握手建立连接：SYN → SYN+ACK → ACK；四次挥手释放（TIME_WAIT 等待 2MSL）。
  • 流量控制：滑动窗口（接收方通告窗口）；拥塞控制：慢开始（指数增长）、拥塞避免（线性）、快重传/快恢复。
  • TCP 首部最少 20 字节；确认号 = 期望收到的下一个字节序号。
  • 适用：网页/邮件/文件走 TCP；实时音视频、DNS 查询走 UDP。

五、网络设备与层次

网络设备工作在哪一层，决定它认什么地址：

  • 集线器（物理层）：比特广播，不认地址，共享冲突域。
  • 交换机（数据链路层）：按 MAC 表转发，隔离冲突域、不隔离广播域。
  • 路由器（网络层）：按路由表转发 IP 分组，隔离冲突域与广播域。
  • 网关（高层）：协议转换。

记忆锚点：VLAN 也能隔离广播域；「隔离广播域」的只有路由器和 VLAN，判断题就考这个集合。
