プラグインをインストールして AI に「X を学びたい」と伝えれば、学習サイトが立ち上がります。以下からツール別に手順を選んでください。どれも実際に動作確認済みのコマンドです。

## ツール別インストール

ツールごとにインストール方法が異なり、複数のツールを使う場合はそれぞれにインストールします。プラグインにクイズアプリの完全なソースが同梱されているため、インストール後にこのリポジトリを clone する必要はありません。

**Claude Code**（2 ステップ、両方実行）

```text
/plugin marketplace add https://github.com/jerryjiao/ai-study-kit
/plugin install ai-study-kit@ai-study-kit
```

**zcode** プラグインマーケットを開き、リポジトリ `https://github.com/jerryjiao/ai-study-kit` を追加して、ai-study-kit をインストールします。

**Codex**（2 ステップ、両方実行）

```text
codex plugin marketplace add jerryjiao/ai-study-kit
codex plugin add ai-study-kit@ai-study-kit
```

**その他の AI CLI**（skills ディレクトリを認識するものすべて）はリポジトリ付属のインストールスクリプトを使います

```bash
git clone https://github.com/jerryjiao/ai-study-kit
cd ai-study-kit && pnpm run skill:install   # ~/.agents/skills/ へインストール
# または指定ディレクトリへ：bash scripts/install-skill.sh --dest ~/.claude/skills
```

**Cursor、Copilot など**は Agent Plugins 標準マニフェスト経由で対応。インストール方法は各ツールのプラグインドキュメントを参照してください。

## インストール後に起こること

AI に「X を学びたい」と伝えるか、[`/ask-coach`](/ja/ai/ai-study-kit/) を実行します。コーチはまず学習状態（トピック・進捗・間違い・期日の来たフラッシュカード・AI 設定）を走査し、今いちばんやるべきことを推薦してから、実行に付き添います。プロジェクトの初期化、新しいトピックの開始、問題とコースの生成から、間違えた問題の総復習、デプロイまで、13 のフローをすべてカバーします。

学習プロジェクト（クイズアプリ＋あなたのトピックパック）は自分のディレクトリに置かれ、プラグインのアップグレードと干渉しません。プラグインの更新後、旧プロジェクトにはバージョン通知が届き、アップグレードはデータを保持した短いフローです。

プロジェクトに完成済みの問題集は同梱されていません。問題は自分で集めた本番問題でも、AI エージェントに生成させてもかまいません。`/ask-coach` を入れたら「このトピック用に問題集を一式作って」と伝えるだけです。流れは[自分のトピックに変える](/ja/your-theme/)の「AI エージェントに問題を生成してもらう」にあります。

何もインストールしたくない場合は、まず[オンラインデモを試す](/demo/)ことを。機能は完全で、進捗はブラウザにしか保存されません。

## 開発者向け：デモをローカルで動かす（clone ルート）

デモをローカルで動かしてコードを見たい場合は、次の 4 コマンドを実行します。

```bash
git clone https://github.com/jerryjiao/ai-study-kit
cd ai-study-kit
pnpm install
pnpm dev
# ブラウザで http://localhost:5173 を開く
```

起動すると表示されるのは dev-intro サンプルトピック（git と Linux の基礎）で、3 つのタブの中身は以下のとおりです。

| 上部タブ | 表示される内容 |
|---------|-------------|
| **クイズ** | git/Linux の問題 10 問（単一選択・複数選択・正誤判定）。送信で即採点、複数選択は全問正解が必要。間違いは間違えた問題に記録され、正解すると解説が表示されます |
| **フラッシュカード** | SM-2 間隔反復カード 4 枚。again / hard / good / easy で評価、アルゴリズムは Anki 互換 |
| **コース** | 自己完結型 HTML コース 2 回（git の三領域、Linux のディレクトリと権限）。ASCII 図とコールアウト付き |

> これはあくまでデモです。dev-intro トピックの内容は後で全部入れ替えて、実際に学んでいるものに差し替えます。[自分のトピックに変える](/ja/your-theme/)を参照してください。

## AI なしでも使えます

3 つの AI CLI は追加機能です。クイズアプリとフラッシュカードだけ欲しい場合は、LLM の設定も CLI の実行も不要で、`pnpm dev` だけで十分です。

さらに進みたい場合は、以下を参照してください。

- [自分のトピックに変える](/ja/your-theme/)——30 分でデモを学習中の内容に変える
- [学習メソッド](/ja/method/methodology/)——なぜ「アウトライン → 資料 → 演習」なのか
- [AI CLI ガイド](/ja/ai/ai-cli/)——AI にコース・間違えた問題の徹底解説・ポッドキャストを生成させる
