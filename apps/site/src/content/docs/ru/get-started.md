Поставьте плагин, скажите ИИ «хочу выучить X» — и ваш учебный сайт уже работает. Ниже выберите свой инструмент; каждая команда здесь реально проверена.

## Установка под ваш инструмент

Шаги установки зависят от инструмента, и каждому нужна своя копия. Плагин везёт полный исходный код приложения, клонировать репозиторий не нужно.

**Claude Code** (два шага, выполните оба)

```text
/plugin marketplace add https://github.com/jerryjiao/ai-study-kit
/plugin install ai-study-kit@ai-study-kit
```

**zcode**: откройте маркетплейс плагинов, добавьте репозиторий `https://github.com/jerryjiao/ai-study-kit` и установите ai-study-kit.

**Codex** (два шага, выполните оба)

```text
codex plugin marketplace add jerryjiao/ai-study-kit
codex plugin add ai-study-kit@ai-study-kit
```

**Любой другой ИИ-CLI**, понимающий каталог skills, может использовать встроенный установщик:

```bash
git clone https://github.com/jerryjiao/ai-study-kit
cd ai-study-kit && pnpm run skill:install   # ставит в ~/.agents/skills/
# или выберите каталог: bash scripts/install-skill.sh --dest ~/.claude/skills
```

**Cursor, Copilot и прочие** покрыты стандартным манифестом Agent Plugins; способ установки смотрите в документации плагинов каждого инструмента.

## Что происходит после установки

Скажите ИИ «хочу выучить X» или запустите [`/ask-coach`](/ru/ai/ai-study-kit/). Тренер сначала сканирует состояние учёбы (тема, прогресс, ошибки, карточки к повторению, конфигурация ИИ), рекомендует то одно действие, что сейчас нужнее всего, и проводит вас через него. Тринадцать сценариев покрыты под ключ — развёртывание, новые темы, генерация вопросов и курсов, разборы ошибок, публикация.

Ваш учебный проект (копия приложения + ваши пакеты тем) целиком живёт в вашем каталоге и переживает обновления плагина; после обновления старые проекты получают уведомление о версии, а само обновление — короткая процедура, не трогающая данные.

Готового банка вопросов в проекте нет. Вопросы могут быть собранными вами реальными или целым банком от ИИ-агента — установите `/ask-coach` и просто попросите; процесс описан в [Переделайте под свою тему](/ru/your-theme/), раздел «Пусть ИИ-агент напишет вопросы за вас».

Не хочется ничего ставить? [Откройте онлайн-демо](/demo/) — полная функциональность, прогресс хранится только в вашем браузере.

## Разработчикам: демо локально (маршрут с клонированием)

Если хочется покопаться в коде или запустить демо локально:

```bash
git clone https://github.com/jerryjiao/ai-study-kit
cd ai-study-kit
pnpm install
pnpm dev
# Откройте http://localhost:5173
```

**Что увидите** (демо-тема dev-intro: git + основы Linux):

| Вкладка | Что показывает |
|-----|---------------|
| **Тесты** | 10 вопросов по git/Linux (одиночный/множественный выбор, «да/нет»), оценка при отправке, во множественном нужно всё верно; ошибки попадают в тетрадь ошибок |
| **Карточки** | 4 карточки интервального повторения SM-2, оценки again / hard / good / easy, совместимо с Anki |
| **Курсы** | 2 самодостаточных HTML-урока (три области git, каталоги и права Linux) со схемами ASCII и врезками |

> Это только демо. **Ничего из содержимого dev-intro вы использовать не будете** — замените его тем, что реально учите. См. [Переделайте под свою тему](/ru/your-theme/).

## Работает без ИИ

Три ИИ-CLI — возможности поверх базы. Если нужны только тесты и карточки, пропустите настройку LLM целиком — достаточно `pnpm dev`.
