## Кому это нужно

| Чем вы заняты | Подходит ли |
|------|---------|
| 🧑‍💻 **Разработчик учит новую технологию** (React / K8s / Rust) | ✅ Свести официальную документацию в вопросы и закреплять карточками |
| 📚 **Готовитесь к экзамену** (предмет / сертификация) | ✅ Реальный банк вопросов + ИИ-разборы ошибок |
| 🎯 **Готовитесь к собеседованию** | ✅ Пишете вопросы сами + курсы от ИИ, плюс SRS |
| 🗂️ **Учитесь чему угодно с «пунктами экзамена»** (регламенты, процессы, термины) | ✅ Если раскладывается на вопросы и ответы — этому можно учиться |
| ❌ Ищете готовый банк вопросов | ❌ Это **каркас**, а не банк — соберите реальные вопросы, напишите сами или поручите ИИ-агенту |

**Одной фразой**: это каркас, а не банк вопросов. Вопросы могут быть реальными, собранными вами, написанными вручную или целым банком, сгенерированным ИИ-агентом — установите [`/study-coach`](/ai-study-kit/ai/study-coach/) и просто попросите; процесс описан в [Переделайте под свою тему](/ai-study-kit/ru/your-theme/), раздел «Пусть ИИ-агент напишет вопросы за вас». Как только вопросы лежат в JSON, инструмент добавляет курсы, карточки, разбор ошибок и планирование повторений.

Не хочется клонировать? [Откройте онлайн-демо](/ai-study-kit/demo/) — полная функциональность, прогресс хранится только в вашем браузере.

## Демо за 5 минут

```bash
git clone https://github.com/jerryjiao/ai-study-kit
cd ai-study-kit
pnpm install
pnpm dev
# Откройте http://localhost:5173
```

**Что вы увидите** (пример темы dev-intro: git + основы Linux):

| Вкладка | Что показывает |
|-----|---------------|
| **Тесты** | 10 вопросов по git/Linux (одиночный/множественный выбор, «да/нет»), оценка при отправке, во множественном нужно всё верно; ошибки попадают в тетрадь ошибок |
| **Карточки** | 4 карточки интервального повторения SM-2 с оценками again / hard / good / easy, совместимые с Anki |
| **Курсы** | 2 самодостаточных HTML-урока (три области git, каталоги и права Linux) со схемами ASCII и врезками |

> Это всего лишь демо. **Содержимое dev-intro вы полностью замените** — на то, что действительно учите. См. [Сделайте его своим](/ai-study-kit/ru/your-theme/).

## Работает без ИИ

Три ИИ-CLI — это возможности поверх базы. Если вам нужны только тренажёр и карточки, пропустите настройку LLM целиком — достаточно `pnpm dev`.
