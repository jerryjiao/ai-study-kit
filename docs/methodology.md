# Methodology · 学习方法论

> **EN**: This toolkit encodes a learning pattern distilled from real practice: an official syllabus defines scope, reference materials build concepts, and quizzes validate mastery. AI assists at every layer. Below is the neutralized pattern you can apply to any topic.
>
> **中文**：本工具沉淀了一套从真实学习实践中提炼的方法论——**以能力大纲为纲 → 以参考材料建概念 → 以做题验效果**，AI 在每一层都参与。下面是去掉具体领域绑定后的通用模式，可以套用到任何主题。

---

## 核心模式：大纲 → 材料 → 做题

学习一个领域有三种资料，**性质不同、优先级不同**：

| 资料 | 角色 | 例子 | 权威性 |
|------|------|------|--------|
| **能力大纲 / 考纲** | 定**学什么、学到什么程度** | 学校课程大纲、考证公告、面试题单、OKR 学习目标 | **唯一权威** |
| **参考材料** | 建**概念体系** | 经典教材、官方文档、公开课、高质量博客、AI 老师讲解 | 高（冲突时让位大纲） |
| **练习题** | 验**掌握程度** | 真题、模拟题、自编题、闪卡、错题本 | 中（题目可能有偏） |

**关键认知**：大纲是<strong>权威</strong>，参考材料和练习题都是<strong>工具</strong>。三者对同一概念的描述不一致时，以大纲为准——题目或材料覆盖的内容，大纲未必要求；大纲要求的内容，即便题库没覆盖也要学。

### 何时该学什么

- **大纲列了的，必须覆盖**——这是认证、测验、面试的硬性要求。
- **大纲没列的，不强求**——优先级信号是"可以跳过"，不是"必须学完所有相关内容"。
- **大纲里同一项有等级/深度区分**（如 L1 入门 / L2 进阶 / L3 精通）——按你目标等级准备，不要盲目冲最高级。

## 完整学习闭环（5 个支柱）

本工具把这五个产物围绕同一套知识点对齐：

1. **答题站（quiz-app）**：刷题、判分、错题收集、自动跨设备同步进度。
2. **课程讲解（teach 产物）**：把材料里散落的概念串成系统讲解，HTML 小站，自包含。
3. **闪卡（SRS）**：核心概念做记忆锚点，用 SM-2 + Anki 学习步算法做间隔重复。
4. **错题精讲（grill 产物）**：刷完题后，把高频错点聚类深度展开——不只是看正确答案，要讲清楚<strong>为什么错</strong>、易混点的边界在哪。
5. **复习播客（podcast-generation）**：把课程/题/错题内容做成男女双播音频，通勤、运动时复习。

**AI 在每一层都参与**：
- 出题：AI 协助生成变体、改编题、错题分析。
- 讲课：AI（teach skill）把材料结构化成课程 HTML。
- 闪卡：AI 从课程里提炼核心概念做卡。
- 错题精讲：AI（grill-wrong-questions skill）把错题聚类展开。
- 播客：AI（podcast-generation skill）合成男女主播对话。

## 工作流总览

```
        ┌─────────────────┐
        │  能力大纲（权威） │
        └────────┬────────┘
                 │ 定考点 + 等级
                 ▼
   ┌─────────────────────────┐
   │  参考材料（建概念）        │ ← 教材 / 文档 / 公开课 / AI 老师
   └────────┬─────────────────┘
            │ AI 协助结构化
            ▼
   ┌─────────────────────────┐
   │  teach 课程 HTML          │ ← 系统讲解，自包含小站
   └────────┬─────────────────┘
            │ 四对齐（见下）
            ▼
   ┌─────────────────────────┐
   │  练习题 + 闪卡 + 错题精讲  │ ← 同一考点跨产物覆盖
   └────────┬─────────────────┘
            │ 持续做题
            ▼
   ┌─────────────────────────┐
   │  做题正确率 = 学习效果     │
   └─────────────────────────┘
            ↓
   错的题 → grill skill 聚类精讲 → 补强 → 重做
```

详细对齐规则见 [`four-alignment.md`](./four-alignment.md)，自动化校验脚本见 [`bidirectional-check.md`](./bidirectional-check.md)。

## 给主题作者的话

如果你要把这套方法论用在自己的主题（如 K8s、React、英文单词、某学科复习）：

1. **先定大纲**——不要直接开始刷题。先想清楚你要学什么、学到什么程度。哪怕只是"我要能独立部署一个 K8s 集群"这种粗粒度目标，也比没有强。
2. **找权威材料**——优先官方文档、经典教材。不要让 AI 老师凭空讲，AI 也需要权威输入。
3. **用 teach skill 产出课程**——`teach` 工作流要求你维护 `RESOURCES.md`（外部资源清单），AI 在产课程前先查这里。
4. **做题验证**——可以是真题、模拟题、自编题，关键是<strong>可量化</strong>。正确率不是目的，是诊断信号。
5. **错的题深度展开**——别只看正确答案，问"为什么错、易混点在哪、变体怎么做"。
