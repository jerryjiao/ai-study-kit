# 蒸馏不依赖：吸收外部 skill 一律重写进仓，不做运行时依赖

2026-09-21 grill 八问定案（spec #82）。背景：学习教练（/ask-coach 命令面）的输出有三处不像人话——陪练对话（F10/F11）讲义腔残留（模板套话、空泛措辞、不接话直接开讲）、快照推荐行（Step 2）空话（「错题较多建议复习」不带实测依据）、教练手写产物（学习笔记 / 案例范式卡 / 考前冲刺包）容易讲义搬运。外部表达引擎 skill「辞达（cida）」（MIT，作者「谁是专家」mizzlelover）已有一套口表语域机制。拍板：把它**蒸馏重写**进仓库——新开五 skill 共享的声音纪律文件 `skills/references/voice.md` 作单一事实源（五节结构：§1 通用口表语域底座、§2 快照与推荐措辞、§3 对话层增补、§4 产物成文、§5 排除边界），七条机制取骨架、不照抄原文、不搬知识库全量，文件头保留源流注记。版本线：本刀 v0.19.0 只动 skill 层（skills/ 与文档），CLI 产物 prompt（错题精讲 / 播客稿 / 课程 HTML）留 v0.20.0 第二刀。

决策：**吸收外部 skill 的方法进仓库，一律走「蒸馏重写」——不检测外部 skill 是否存在、不做运行时依赖、不照抄原文。** 三条动机：

1. **插件即发行形态**：教练以 plugin / skill 安装两种形态发行（ADR-0007 安装面），装插件的用户不该被要求「再装一个 cida 才有人话」——依赖外部 skill 等于给最短安装路径加前置条件。
2. **教练声音须确定性**：无装机分裂——所有用户同一个声音，出问题在本仓可复现、可修；声音纪律进了仓库才进版本线与测试面。
3. **许可与先例使重写可行**：cida 为 MIT License，方法骨架重写无版权障碍；本仓吸收 teach skill（0001）、DeepTutor（0005）的一贯做法就是「重写而非删名」——方法重写进仓 + README 致谢点名 + ADR 记源流，不整包搬运。

## Considered Options

- **运行时探测**（装了 cida 用 cida、没装退回内置 voice.md）——拒：声音不确定——同一教练在不同机器上腔调不同，直接违背动机 2；探测逻辑写进 skill 反而占上下文（五 skill 共享协议层要保持薄）；cida 路径 / 内置路径双行为面，测试与排查翻倍。
- **双层增强**（内置 voice.md 底座 + 装了 cida 叠加增强层）——拒：同样是装机分裂；还得维护「哪条纪律允许被增强层覆盖」的协调规则，两套措辞纪律并存违背 voice.md 单一事实源。

## Consequences

- 无 cida 的插件用户拿到与所有人一致的教练声音；voice.md 是五 skill 共享声音纪律的单一事实源，§5 排除边界五条写死（三段式骨架不动，金句通胀条款、十维文体参数、平台适配、个人风格校准不进），文件头保留 cida 源流注记。
- 未来融合其他外部 skill 照此办理：蒸馏重写进仓 + 源流注记 + ADR 记录，不新增运行时依赖、不新增探测逻辑。
- voice.md 的后续维护与 CLI 产物 prompt 刀（v0.20.0）都以本 ADR 为依据；skill 层（v0.19.0）与 CLI 层（v0.20.0）两刀的版本边界也在本 ADR 定死。
