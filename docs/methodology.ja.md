# 学習方法論

[简体中文](methodology.md) · [English](methodology.en.md) · [Español](methodology.es.md) · [Русский](methodology.ru.md) · **日本語**

このツールキットは実際の学習実践から形作られたものです。一言でいうと：**アウトラインが何を問うかを決める → 教材が概念を説く → 問題を解いて効果を検証する**。三つの作業にはそれぞれ権威のある情報源があり、順序を乱せません——先に問題を解いてからアウトラインを探したり、教材で下地を作っていない概念をいきなり問題にしたりすると、労力が無駄になります。以下はドメインとの結び付きを取り除いた汎用パターンで、どんなテーマにも当てはめられます。

---

## コアパターン：アウトライン → 教材 → 問題演習

一つの領域を学ぶとき、性質も優先度も異なる三種類の資料に向き合います：

| 資料 | 役割 | 例 | 権威性 |
|------|------|------|--------|
| **能力アウトライン／試験アウトライン** | **何を、どの深さまで学ぶか**を決める | 学校のシラバス、資格試験の公告、面接問題リスト、OKR の学習目標 | **唯一の権威** |
| **参考資料** | **概念体系**を作る | 定番教科書、公式ドキュメント、公開講義、質の高いブログ、AI 講師の解説 | 高い（アウトラインと衝突するときは譲る） |
| **練習問題** | **習得度**を検証する | 過去問、模擬問題、自作問題、フラッシュカード、間違えた問題ノート | 中（問題には偏りがありうる） |

アウトラインが権威であり、参考資料と練習問題はどちらも道具です。三者が同じ概念を異なる説明で述べているときは、アウトラインに従います——問題や資料がカバーしている内容をアウトラインが要求しているとは限りませんし、アウトラインが要求する内容は、問題バンクでカバーされていなくても学ぶ必要があります。

### 何をいつ学ぶべきか

- **アウトラインに列挙されているものは必ずカバーする**——資格、テスト、面接の必須要件です。
- **アウトラインにないものは無理に学ばない**——「スキップしてよい」であり、「関連する内容をすべて学び切る必要がある」ではありません。
- **同じ項目に等級の区別がある場合**（例：L1 入門 / L2 中級 / L3 上級）——目標とする等級に合わせて準備し、むやみに最上級を狙いません。

## 完全な学習ループ

ツールは同じ出題ポイントのセットを軸に五種類の成果物を編成し、さらにコーチのラインと学習痕跡の一式を加えます：

### 五種類の成果物

1. **クイズアプリ（quiz-app）**——問題演習、採点、間違えた問題の収集。進捗は端末間で自動同期されます。
2. **コース解説（teach CLI が生成）**——教材に散らばった概念を体系的な講義につなぎ合わせた、自己完結型の HTML ミニサイト。レッスンは「✓ 学習完了」で明示的に確認して初めて進捗に計上されます——開いただけではだめで、学び終えて初めて学習済みです。
3. **フラッシュカード（SRS）**——核心概念を記憶のアンカーにし、SM-2 + Anki 学習ステップのアルゴリズムで間隔反復を行います。
4. **間違えた問題の徹底解説（grill CLI が生成）**——高頻度の誤答ポイントをクラスタリングし、クラスタごとに深掘りします。なぜ間違えたのか、混同しやすい境界はどこかを明らかにし、正答を示すだけにとどまりません。
5. **復習ポッドキャスト（podcast CLI が生成）**——コース、問題、徹底解説を男女二人のナレーターによる対話音声に合成し、通勤や運動中に復習できます。

### コーチライン：`/ask-coach`

機能が増えると、「今日は結局何をすべきか」がかえって負担になります。`/ask-coach` 学習コーチがルーティングを担います：毎回まず読み取り専用で学習状態を検出し、理由付きのおすすめアクションを一つ示し、選ばれた後は playbook に沿って実行を伴走します。そのうち二つのフローは、方法論のより深い主張に直接対応します：

- **F10 伴走型指導**——レッスンは一方向、伴走は対話です：出題ポイントごとに「何か／なぜか／いつ使うか」を説き、その場で問い、間違えたらその場で軌道修正します。これは「参考資料で概念を作る」の対話型の補完です。
- **F11 試験直前スプリント**——試験日まで 7 日以内になると刈り取りウィンドウに入ります：既に学んだもの（キーフレーズ、間違えた問題の記録）だけを刈り取り、新しいレッスンは追加せず、暗記が済んだら模擬試験で検証します。

### 学習痕跡：`study/`

テーマパック内の学習成果物はすべて `study/` 以下に置かれ、四分法でそれぞれの場所に収まります：

| ディレクトリ | 内容 | 性質 |
|------|------|------|
| `study/records/` | 伴走指導の進捗記録（出題ポイントごとの記録、アンカーとなるキーフレーズ） | 学習者の私有データ。**静的サイトとして決して公開されない** |
| `study/notes/` | 段階ノート（伴走指導の成果物、問題演習への引き継ぎ用） | テーマパックと共に配布 |
| `study/wrong-questions/` | 間違えた問題の徹底解説（grill が生成） | テーマパックと共に配布 |
| `study/sprint/` | 試験直前スプリントパック（キーフレーズの速記／間違いやすいポイントの注意／必須暗記リスト／チェックリスト） | テーマパックと共に配布 |

AI はどの層にも関わります：出題（エージェントがアウトラインに沿って出題ポイントごとに直接生成、[`ai-study-kit.ja.md`](./ai-study-kit.ja.md) の F2 フローを参照）、講義（teach）、伴走（F10 の対話式指導）、カード作成（コースから概念を蒸留）、間違えた問題の深掘り（grill）、ポッドキャスト合成（podcast）。これらの成果物がどう同じ出題ポイントのセットを軸に保たれるかは、[`four-alignment.ja.md`](./four-alignment.ja.md) を参照してください。

## ワークフロー概観

```
        ┌─────────────────┐
        │  能力アウトライン（権威） │
        └────────┬────────┘
                 │ 出題ポイントと等級を定める
                 ▼
   ┌─────────────────────────┐
   │  参考資料（概念を作る）    │ ← 教科書 / ドキュメント / 公開講義 / AI 講師
   └────────┬─────────────────┘
            │ AI が構造化を支援
            ▼
   ┌─────────────────────────┐
   │  teach コース HTML        │ ← 体系的解説 + F10 伴走型の対話式解説
   └────────┬─────────────────┘
            │ 四つの整合（下記）
            ▼
   ┌─────────────────────────┐
   │  練習問題 + フラッシュカード + 徹底解説 │ ← 同じ出題ポイントを成果物横断でカバー
   └────────┬─────────────────┘
            │ 継続的に問題を解く
            ▼
   ┌─────────────────────────┐
   │  正答率 = 学習効果        │
   └─────────────────────────┘
            ↓
   間違えた問題 → grill がクラスタリングして徹底解説 → 補強 → やり直し
   試験日が近づく → F11 スプリントパックで刈り取り → 模擬試験で検証
```

## テーマ作者への言葉

この方法論を自分のテーマ（K8s、React、英単語、どんな学問でも）に当てはめるには：

1. **まずアウトラインを定める**——いきなり問題演習を始めません。何を、どこまで学ぶかを明確にし、`examples/<theme>/MISSION.md` に書きます。「K8s クラスターを自力でデプロイできるようになりたい」程度の粗い目標でも、ないよりはるかにましです。
2. **権威ある資料を集める**——公式ドキュメントと定番教科書を優先し、リンクは `examples/<theme>/RESOURCES.md` に集めます。AI 講師もやはり権威ある入力が必要です。空想で語らせないこと。
3. **コースを生成する**——目標、対象読者、深さ、資料リンクを `examples/<theme>/course-spec.json` に書き、`pnpm run ai:teach` でコースを生成します。
4. **問題で検証する**——過去問、模擬問題、自作問題のどれでもよく、重要なのは**定量化できること**です。正答率は目的ではなく、診断シグナルです。
5. **間違えた問題を深掘りする**——正答だけを見ず、「なぜ間違えたのか、どこが混同しやすいか、バリエーションはどう解くか」を追及します。間違えた問題を貯めて、grill CLI にクラスタリングと徹底解説を任せます。

フロー全体を手動で歩く必要はありません——`/ask-coach` コーチをインストールしたら「X を学びたい」と一言いうだけで、F2 新テーマフローが上の順序で最後まで伴走してくれます。
