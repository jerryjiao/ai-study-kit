**Одной фразой**: скажите ИИ «хочу выучить X» — коуч согласует с вами пункты программы, сам напишет вопросы и курсы и будет тренировать вас до результата. Банк вопросов приносить не нужно; остальное инструмент превратит в законченное учебное приложение с курсами, карточками и разбором ошибок.

## 👋 Кому это подходит

| Чем вы заняты | Подходит ли |
|---------------|-------------|
| 🧑‍💻 **Разработчик учит новый стек** (React / K8s / Rust) | ✅ ИИ сводит документацию в вопросы; закрепляйте карточками |
| 📚 **Студент готовится к экзамену** (предмет / сертификация) | ✅ Есть реальные экзамены? Импортируйте. Нет? ИИ напишет вопросы по вашим пунктам |
| 🎯 **Готовитесь к собеседованию** (основы / дизайн систем) | ✅ Скажите, куда собеседуетесь, — ИИ сделает курсы и вопросы и проведёт вас по ошибкам |
| 🗂️ **Учитесь чему угодно с «пунктами экзамена»** (регламенты / процессы / термины) | ✅ Если раскладывается на «вопрос + ответ» — этому можно учиться |
| ❌ Нужен готовый банк вопросов («500 вопросов по Java») | ❌ Готовых вопросов здесь нет — но ИИ может сгенерировать набор по вашим пунктам (с вашим API-ключом) |

Хотите сначала посмотреть вживую? Маршрут с клонированием ниже.

## 🚀 Запустить демо (маршрут с клонированием, для разработчиков)

```bash
git clone https://github.com/jerryjiao/ai-study-kit
cd ai-study-kit && pnpm install && pnpm dev
# откройте http://localhost:5173
```

В комплекте пример на git + Linux: **тесты** (одиночный/множественный выбор, «да/нет»; оценка при отправке, ошибки в журнале), **карточки** (интервальное повторение SM-2, алгоритм совместим с Anki), **курсы** (самодостаточные HTML-уроки со схемами и врезками). Это просто демо — для реального использования подключите свою тему (следующий раздел).

## 🧭 Не знаете, за что взяться? `/ask-coach`

После установки плагина (или `pnpm run skill:install` в `~/.agents/skills/`) каждая учебная сессия начинается отсюда. Пять команд: `/ask-coach` спрашивает коуча, что делать дальше (снимок состояния + рекомендация + ведение по шагам), `/study-coach` садит за учёбу сразу, `/study-doctor` запускает полную проверку, `/study-recap` открывает разбор ошибок, `/study-podcast` открывает генерацию подкаста.

`/ask-coach` сначала **сканирует ваше состояние** (прогресс, карточки с истёкшим сроком, ошибки, завершённые курсы, настройки ИИ), затем **советует одно самое полезное действие на сейчас** и после выбора **ведёт вас по шагам** — от инициализации проекта до деплоя, тринадцать процессов. Подробности: [`docs/ai-study-kit.ru.md`](docs/ai-study-kit.ru.md).

## 🔧 Переделайте под свою тему

Пример: учите **основы React**. Меняются только файлы в `examples/`, код приложения не трогается:

1. **Скопируйте каталог темы**: `cp -r examples/dev-intro examples/react-basics` (может жить и вне репозитория — путь с разделителями считается внешним пакетом темы, см. [`docs/adr/0004`](docs/adr/0004-external-theme-packs.md))
2. **Правьте вопросы** `questions.json`: каждый вопрос — простой JSON — формулировка + варианты + ответ + разбор (полная схема в интерфейсе `Question` файла [`apps/quiz-app/src/types.ts`](apps/quiz-app/src/types.ts)):

   ```json
   {
     "id": "R-001",
     "type": "single",
     "source": "react-basics",
     "topic": "react-basics",
     "question": "Что возвращает useState в React?",
     "options": {
       "A": "Текущее значение состояния",
       "B": "Функцию обновления состояния",
       "C": "Массив [state, setState]",
       "D": "Объект { state, setState }"
     },
     "answer": ["C"],
     "analysis": "useState возвращает массив из двух элементов: текущее состояние и функцию обновления. Обычно используется с деструктуризацией."
   }
   ```

3. **Правьте карточки** `flashcards.json`: вопрос спереди, разбор сзади — так же просто
4. **Переключите**: `EXAMPLE_THEME=react-basics pnpm dev` — обновите страницу, и тема внутри
5. **(Необязательно) курсы и оформление**: курсы лежат в `lessons/*.html`; группировка и подписи главной — в `theme-config.json` (см. [`docs/theming.ru.md`](docs/theming.ru.md)); без него — мягкий откат
6. **Четыре проверки**: `pnpm run scan` (ноль совпадений) + `pnpm test` + `pnpm run build` + `python3 scripts/bidirectional-check.py examples/react-basics/` (четырёхстороннее выравнивание)

**Не хотите писать вопросы вручную?** С установленным `/ask-coach` скажите «сгенерируй банк вопросов для react-basics» — агент сначала согласует с вами **таблицу пунктов программы** в MISSION.md (что проверяется, насколько глубоко, сколько вопросов каждого типа, сколько карточек), затем после вашего подтверждения пишет вопросы и карточки пункт за пунктом и перед сдачей прогоняет три рубежа качества (`qa` / `scan` / выравнивание). Ручной путь остаётся главным; таблица — контракт между вами и агентом.

## 🤖 Пусть ИИ делает курсы / разборы ошибок / подкасты

В репозитории три ИИ-утилиты командной строки (подойдёт любая LLM, совместимая с OpenAI; TTS пока поддерживает GLM-TTS):

| CLI | Что делает | Результат |
|-----|------------|-----------|
| `teach-generate.mjs` | Превращает спецификацию темы в многосекционные HTML-курсы | `lessons/*.html` |
| `grill-wrong.mjs` | Группирует ошибки по пунктам программы и разбирает каждую группу | `wrong-questions/*.html` + профиль ошибок по пунктам |
| `podcast-generate.mjs` | Превращает любой учебный материал в аудио с двумя ведущими | `.wav` + сценарий JSON + транскрипт |

Настройка: `cp .env.example .env`, затем заполните как минимум `LLM_BASE_URL / LLM_API_KEY / LLM_MODEL` (см. [`docs/configuration.ru.md`](docs/configuration.ru.md)); использование и параметры — в [`docs/ai-cli-guide.ru.md`](docs/ai-cli-guide.ru.md).

> 💡 **ИИ необязателен**: три CLI — дополнительные возможности. Нужен только тренажёр + карточки? LLM можно вообще не настраивать — достаточно `pnpm dev`.

## 🎯 Зачем этот инструмент

| Без ai-study-kit | С ai-study-kit |
|-------------------|-----------------|
| **Anki** силён в карточках, но без тренажёра, без разбора ошибок, без курсов | 6 учебных артефактов в одном приложении, вокруг одних и тех же пунктов |
| **Quizlet** с вопросами и карточками, но это закрытый SaaS — данные не ваши | Открытый код MIT; данные у вас на машине + вашем сервере; синхронизация без аккаунтов |
| **Заметки Notion** записывают, но не тренируют; без алгоритма интервалов | Встроенный SM-2, совместимый с Anki, + учебные шаги Anki |
| **PDF / Word с вопросами** только для чтения — без оценки и статистики | Автооценка, журнал ошибок, статистика точности, планирование SRS |
| **Прямой вопрос ChatGPT** даёт разрозненные знания без учебного маршрута | ИИ собирает разрозненное в курсы + вопросы + карточки |

**Ключевое отличие**: **цикл четырёхстороннего выравнивания** — пункты, которые объясняют курсы, проверяют тесты, закрепляют карточки и разбирают разборы ошибок, — это один и тот же набор (см. [`docs/four-alignment.ru.md`](docs/four-alignment.ru.md)).

## 🛠️ Разработка и деплой

```bash
pnpm install        # установить зависимости
pnpm run dev        # локальная разработка (фронтенд :5173 + бэкенд :8787)
pnpm test           # тесты
pnpm run scan       # скан на бренды
pnpm run check:alignment  # проверка выравнивания
pnpm run skill:install    # установить команды коуча в ~/.agents/skills/
```

Полная таблица команд, продакшн-деплой (pm2) и устройство синхронизации между устройствами: [`AGENTS.md`](AGENTS.md) и [документация на сайте](https://aistudykit.dev/ru/).

## 🤝 Как внести вклад

PR и issues приветствуются. Перед PR:

1. Запустите `pnpm run scan` — ноль совпадений
2. Запустите `pnpm test` — всё зелёное
3. Меняли артефакты (курсы / вопросы / карточки / разборы)? Прогоните и [`bidirectional-check`](docs/bidirectional-check.ru.md)
4. Следуйте [Conventional Commits](https://www.conventionalcommits.org/)
