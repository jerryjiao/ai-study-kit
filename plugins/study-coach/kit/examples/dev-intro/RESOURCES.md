# Resources · dev-intro 示例

> teach 工作流约定：每个学习工作区维护一份高质量外部资源清单，AI 老师在备课前先来这里查权威。

这个示例主题（git + Linux 基础）的权威资源：

## 官方文档（最高优先级）

- **Pro Git Book**（官方，免费）：https://git-scm.com/book/zh/v2
  - 中文版，完整覆盖 git 全部概念。本示例的"三区模型""reset/revert"都基于第 1-2 章。
- **git 官方 reference**：https://git-scm.com/docs
  - 每条命令的权威手册（man page 的 web 版）。
- **Linux man pages**：终端里 `man ls` / `man chmod`
  - 最权威的命令文档，离线可用。

## 高质量补充

- **Linux 命令大全（runoob）**：https://www.runoob.com/linux/linux-command-manual.html
  - 中文，例题丰富，适合入门补充。
- **Learn Git Branching**（交互式）：https://learngitbranching.js.org/?locale=zh_CN
  - 可视化学 git 分支操作，强化 reset/rebase 等抽象概念。

## 资源使用规则（teach 原则）

1. **官方文档 > 教程书 > 博客**——讲概念必引官方文档原文链接。
2. **冲突时以官方为准**——博客和教程偶尔有过时或简化错的描述。
3. **离线优先**——`man` 和 `--help` 永远是最快的，养成习惯。
