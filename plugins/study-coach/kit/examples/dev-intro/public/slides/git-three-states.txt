                git 三区流转图
                =================

   Working Directory          Staging Area            Repository (.git)
  ┌─────────────────┐       ┌─────────────────┐       ┌─────────────────┐
  │  你的工作目录    │       │   暂存区         │       │   版本库          │
  │  (工作区)        │       │   (index)        │       │   (HEAD)         │
  │                  │       │                  │       │                  │
  │  README.md       │       │  待提交的快照    │       │  commit 历史     │
  │  src/app.ts      │       │                  │       │                  │
  │  ...             │       │                  │       │                  │
  └────────┬────────┘       └────────┬────────┘       └────────┬────────┘
           │                         │                         │
           │   git add <file>        │   git commit -m "..."   │
           └────────────────────────►└────────────────────────►│
                                     │                         │
           ◄─────────────────────────┘ ◄────────────────────────
                   git restore --staged        git checkout / reset
