            chmod 权限三位数对照表
            =====================

   ┌─────────────────────────────────┐
   │        权限位三组：所有人        │
   │                                 │
   │     owner    group    others    │
   │     所有者   所属组   其他人    │
   │     ↓        ↓        ↓         │
   │     r w x    r w x    r w x     │
   │     4 2 1    4 2 1    4 2 1     │
   └─────────────────────────────────┘

读(r)=4  写(w)=2  执行(x)=1    每组三位相加：

  7 = rwx   (读+写+执行)
  6 = rw-   (读+写)
  5 = r-x   (读+执行)
  4 = r--   (只读)
  0 = ---   (无权限)

常见组合：
  chmod 755 file   →  rwxr-xr-x   (所有者全权，其他人读+执行)
  chmod 644 file   →  rw-r--r--   (所有者读写，其他人只读)
  chmod 600 ~/.ssh/id_rsa  →  rw------- (仅所有者读写，密钥必须)

易错：脚本要执行必须给 x，给 r 不够。
