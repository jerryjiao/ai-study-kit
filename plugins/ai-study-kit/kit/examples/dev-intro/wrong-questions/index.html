→ git reset vs git revert：撤销 commit 的两条路

高频易错

考题 GIT-007 错点。两条命令都能"撤销 commit"，但机制完全不同：reset 抹历史、revert 加反向。本地 vs 团队分支选错的代价是协作冲突。包含：核心区别表、决策流程图、易错警示、变体题。

如何用 ai-study-kit 给自己的主题生成错题精讲

  1. 用答题站刷完一批题，错题自动进错题集。
  2. 调用 grill-wrong-questions skill，把错题按考点聚类，每个聚类产出一份 HTML 精讲。
  3. HTML 放到 wrong-questions/cluster-NN-*.html，主页（本文件）加一条卡片链接。
  4. 每个精讲要满足四对齐：能追溯到对应 day 的课程（题→课）、能引到对应的闪卡（错题→闪卡）。

💡 这是 ai-study-kit 的示例。换主题时，把这里的 cluster-01-* 换成你自己题库的错题聚类即可。
