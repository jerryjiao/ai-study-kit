这是 ai-study-kit 的虚构示例主题——git + Linux 基础入门。让 fork 仓库的人 5 分钟内看懂「课程讲解 + 闪卡 + 刷题 + 错题精讲」四对齐闭环长什么样。

📚 课程列表

第 1 课 · git 三区与基础命令

工作区/暂存区/版本区三区模型，add/commit/log/status 四条基础命令，reset vs revert 撤销。

 第 2 课 · Linux 目录与权限

Linux 目录树、绝对/相对路径、权限字段三组、chmod 三位数字。

🔥 错题精讲

→ 错题学习中心

高频错点聚类精讲（如 git reset vs git revert）。

关于本示例

这个示例主题与任何特定测评或职业领域无关——它纯粹是工具能力的演示。换成自己的主题（K8s、React、英文单词、某学科复习等）只需：

  1. 把 questions.json / flashcards.json 换成你自己的内容。
  2. 用 teach skill 产出自己的 lessons/*.html。
  3. 用 grill-wrong-questions skill 产出错题精讲。

详细工作流见仓库根 docs/methodology.md 和 docs/four-alignment.md。
